# Skill Creator 教学快照

这些文件来自本机 Codex 内置 `skill-creator`，按 `来源.json` 中的哈希原样保留，供本讲直接调用原生 Skill、初始化脚本和基础校验脚本。上游英文说明与脚本提示保持原样；Notebook 以中文解释调用目的与结果。

`init_skill.py` 建立目录骨架；`generate_openai_yaml.py` 写入界面元数据；`quick_validate.py` 检查文件结构。这些检查不能判断排障方法是否适用于新事故。只在本讲临时运行目录执行，不安装个人 Skill。YAML 解析沿用现有实验环境的 PyYAML，没有新增依赖。
