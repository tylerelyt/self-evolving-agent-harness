# 超时初查

1. 用 query_service_health 查询服务健康，再用 query_upstream_latency 查询上游延迟。
2. 如果服务不健康，或上游 P95 大于 1000 毫秒，报告已经观测到的异常，并提出后续调查建议。本轮到此结束，不追加连接池查询。
3. 如果健康与上游均正常，但超时仍存在，报告当前证据不足，保留未知原因。不要把缺少检查写成已经排除故障。
4. 报告只引用实际工具回执；同时出现的现象不等于因果。不得变更服务配置。
