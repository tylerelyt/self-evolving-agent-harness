# 旧日志字段对照（构造材料）

参考正文标记：{{REF}}。

| 旧字段 | 当前含义 | 读取时注意什么 |
| --- | --- | --- |
| ts | 日志时间 | 先找告警开始后的最早异常 |
| rid | request_id | 同一请求可能有多条记录；用编号关联，不只看相近时间 |
| node | 实例名 | 同一个模块的不同实例不能混作一条调用链 |
| ver | 实例版本 | 与发布记录和运行配置相互核对 |
| peer | 下游服务 | 判断异常发生在哪段依赖调用 |
| host | 调用域名 | 与当前配置、依赖迁移记录对照 |
| err | 异常类型 | DNS_FAIL 表示域名解析失败，不能直接推出连接池耗尽 |

本例日志的字段名与样本都是构造值；表格用于解释口径，不预先给出本次根因。
